# UoE Teaching Workspace

This directory contains University of Essex Online teaching-support tooling built on the HRP Transfer Lab research platform.

## Current component

- `module-knowledge-graph/` — provenance-first extraction of unit-level concepts, claims, evidence, theories, constructs and pedagogical relationships from a small set of core readings.

## Boundary

This workspace reuses the shared HRP Transfer Lab knowledge-bank, vector and RAG architecture rather than creating a separate retrieval stack.

Source materials should remain traceable to their reading, section/page and passage. Model-generated relationships are proposals until reviewed.

Do not commit copyrighted source PDFs, student submissions, identifiable student data or private embeddings to this repository.
