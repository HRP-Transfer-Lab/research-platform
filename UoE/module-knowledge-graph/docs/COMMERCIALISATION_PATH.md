# Commercialisation Path

## Working product category

**Evidence-grounded course intelligence**

The initial product should serve lecturers and programme teams before expanding into student-facing AI.

## Core proposition

Turn authorised course materials into a reviewed, provenance-aware semantic layer that supports:

- curriculum design;
- teaching preparation;
- assessment alignment;
- programme progression;
- accreditation evidence;
- revision resources;
- eventually institutionally governed AI tutoring.

## Differentiator

The product is not simply:

```text
upload PDFs
→ AI summary
```

It is:

```text
source material
→ provenance-preserving extraction
→ reviewed knowledge graph
→ evidence / theory / construct / prerequisite structure
→ academic approval
→ multiple controlled views and tools
```

## Product layers

### Lecturer layer

- unit/course knowledge graph
- nine derived teaching views
- learning-outcome alignment
- assessment alignment
- reading coverage
- course-design warnings

### Programme layer

- cross-module prerequisite graph
- duplication and gaps
- progression
- outcome coverage
- accreditation mapping

### Student layer

Only from approved course graph:

- revision maps
- source-grounded explanations
- theory comparison
- quizzes
- adaptive remediation
- evidence tracing

## Deployment models to preserve

- local processing;
- university-hosted/on-premise processing;
- private cloud;
- optionally authorised external model providers.

## Evaluation before productisation

Measure:

- graph precision;
- provenance accuracy;
- academic review burden;
- time saved;
- usefulness of each derived view;
- curriculum issues detected;
- reproducibility;
- source-boundary compliance;
- lecturer willingness to reuse/recommend/pay.
